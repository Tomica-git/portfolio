# チップ強度評価 図解画像生成プロンプト

## 用途

`index.html` の「なぜチップ強度を評価するのか」セクションで使う、公開用に一般化した横長インフォグラフィック画像の生成プロンプトです。

出力先の想定:

```text
assets/images/chip-strength-infographic.png
```

## 参照したローカル素材

- `ウェハの該当.png`
- `解決策.png`
- `職場での苦悩.png`

上記から、ウェハ・チップ・工程フロー・2台PC作業の負担感など、公開しても差し支えない概念だけを抽出し、実製品名・会社名・実測値・機密情報は入れない前提で構成します。

## 画像生成AI向けプロンプト

横長の清潔な説明用インフォグラフィックを作成してください。現場写真風ではなく、採用担当者や非エンジニアが3分で理解できる日本語ラベル付きの図解にします。

テーマ:
半導体メモリの評価工程で、なぜチップ強度を評価するのか。

入れる工程の流れ:
ウェハ → ダイシング → チップ → 弱い力でピックアップ → 基板実装 → ワイヤ接続 → 樹脂封止 → 検査

入れる説明要素:
- ウェハから多数のチップが作られる
- ウェハを切断してチップに分ける
- チップを装置が弱い力でピックアップする
- 基板に載せる
- ワイヤ接続する
- 樹脂で封止する
- 脆いチップがあると、割れ・欠け・微小クラック・接続不良・歩留まり低下につながる場合がある
- ウェハ外周部は、切断時の欠けや応力の影響を受けやすく、中央部より強度にばらつきが出る場合がある
- そのため「どのくらいの弱い力なら安全に持ち上げられるか」の境目を評価する

画面構成:
- 左から右へ流れる工程フロー
- 左側にウェハの円形図とチップ格子
- 中央にダイシング、チップ、ピックアップの図
- 右側に基板実装、ワイヤ接続、樹脂封止、検査の図
- 下部に「外周部と中央部の強度ばらつき」イメージを小さく入れる
- 不良例として「割れ」「欠け」「微小クラック」「接続不良」「歩留まり低下」をアイコン付きで入れる

文言トーン:
- 初心者向け
- 短い日本語ラベル
- 断定しすぎず「場合がある」「傾向を見る」「境目を評価する」を使う

デザイン:
- 白背景
- 清潔感のある技術系図解
- 色は青緑、紺、薄いグレー、注意色の淡い赤をバランスよく使う
- 文字は読みやすく、詰め込みすぎない
- LPに埋め込んだときに横長で見やすい

禁止:
- 会社名、実製品名、ブランド名を入れない
- 実測値、実チップサイズ、実圧力値を入れない
- 機密情報に見える内部構造を描かない
- 「完全に防止」「保証」などの断定表現を使わない
